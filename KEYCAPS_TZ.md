# ТЗ: публичный репозиторий `multilang-keycaps`

Параметрический генератор 3D‑печатных MX‑кейкапов с четырёхъязычными легендами
(EN / RU / UK / DE) под многоцветную FDM‑печать (Bambu Lab H2D, AMS).
Исходная реализация — `keycaps_gen.py` рядом с этим файлом. Она рабочая: возьми её как основу, не переписывай с нуля.

## Контекст

- Целевая клавиатура: GravaStar Mercury K98 Pro (MX‑свитчи, 98% ANSI), также Mercury V75 (MX‑стем).
- Печать лицом вниз на гладкой пластине. На клавишу экспортируется 4 тела:
  - `_base` — прозрачный PETG (стенки + стем, RGB просвечивает)
  - `_top` — чёрный PETG‑CF (крышка 2,2 мм с карманами под легенды)
  - `_legA` — белый PETG (EN + DE)
  - `_legB` — красный PETG (RU + UK)
- Профиль: плоский XDA‑подобный, 18×18×9 мм для 1u, верхняя площадка 14×14 мм.
- Схема легенд на клавише:
  ```
  EN      RU
  DE      UK      (UK только там, где отличается от RU: S→І, ]→Ї, '→Є, \→Ґ)
  ```
  DE: `[`→Ü, `;`→Ö, `'`→Ä, `-`→ß.

## Что сделать

### 3. Рефакторинг
- Константы из шапки → `PrintConfig` (dataclass), возможность передать YAML/JSON через `--config`.
- Раскладка → JSON в `layouts/`, генератор её читает. Поле `group` у легенды задаёт цвет (`A`/`B`/…), чтобы количество цветовых групп было произвольным, а не захардкожено 2.
- Стем вынести в отдельную функцию с допусками `stem_clearance` (CF жёстче — сейчас +0,1/+0,05 мм).
- Клавиши ≥2u: сейчас ребро жёсткости; добавить опцию `stabilizer: "none" | "cherry"` — для `cherry` вырезать отверстия под стабилизаторы по стандарту (для 2u: ±11,9 мм; 6,25u: ±50 мм; 2,25u: ±11,9 мм).
- Шрифт: параметр `font_path`, дефолт DejaVu Sans Bold; в README указать, что шрифт должен содержать кириллицу.
- Экспорт: кроме STL добавить **3MF с несколькими объектами‑частями** в одном файле на клавишу (`_base/_top/_legA/_legB` как parts одного object), чтобы в Bambu Studio импортировалось одним перетаскиванием с уже разделёнными частями. Проверить, что Bambu Studio открывает и сохраняет назначение филаментов.
- Опционально: `--plate` — раскладывает N клавиш по пластине с шагом и пишет один 3MF на всю партию (лицом вниз, зазор 3 мм).

### 4. Тесты (pytest)
- Габариты 1u: 18,0 × 18,0 × 9,0 ±0,01.
- Split: `base.zmax == top.zmin == HEIGHT - TOP_THK`.
- Легенды лежат в `[HEIGHT - LEG_DEPTH, HEIGHT]`, объём > 0.
- Легенды не пересекаются между группами и с `top` (после cut) — проверять через `intersect().Volume() ≈ 0`.
- Каждая клавиша из `layouts/ansi_104.json` собирается без исключений (параметризованный тест, можно помечать `slow`).
- CI: ubuntu, python 3.11, `pip install cadquery` (используй официальный wheel; при проблемах — `conda`/`micromamba` action), `apt install fonts-dejavu-core`.

### 5. Рендеры для README
- Скрипт `scripts/render.py`: топ‑проекция легенд в SVG/PNG (пример уже есть в истории: `cq.exporters.export(..., opt={"projectionDir": (0,0,1)})` + cairosvg).
- Собрать картинку‑мозаику буквенного блока (3 ряда) с цветами: белый/красный на чёрном.
